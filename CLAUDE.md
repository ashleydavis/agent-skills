# agent-skills

Personal slash commands (`commands/`) and skills (`skills/`) for Claude and Cursor, installed with `skl` under the `me` namespace. See `README.md`. Remote: `git@github.com:ashleydavis/agent-skills.git`.

- Commands reference rule files in the agent-config repository (`git@github.com:ashleydavis/agent-config.git`) by the path `~/agent-config`, which is assumed to be where it is checked out.
